# 碎星 · Stardust

一个零依赖的网页街机生存射击。双击 `index.html` 就能玩，不需要装 node、不需要构建、不需要联网。

## 玩法

- **WASD / 方向键** 移动，**鼠标瞄准**开火，**Tab** 在「鼠标瞄准 / 自动瞄准」之间切换。枪口跟着准星走，所以打得准比站得稳更重要。
- **空格** 冲刺（短暂无敌 + 位移），冷却环在飞船周围显示进度。
- 击杀敌人掉落蓝色经验碎片，靠近自动吸取；落地 3 秒后碎片会自己飘过来，不会浪费。升满一条经验就 **三选一** 强化（鼠标点，或按 `1` `2` `3`）。
- **卡牌进化**：某张卡叠满后，它的「进化版」才会进入卡池（绿色卡，一次性、质变而不是再加数值）——破甲弹（命中爆炸）、回旋刃（环刃更大更快、命中击退）、过载（射速再提、连击上限 ×4）。卡池被抽干时自动补「保底卡」，不会把玩家卡在空界面。
- **连击倍率**：1.35 秒内连续击杀会把连击数叠上去，得分倍率最高 ×3，右上角实时显示。断杀就清零。
- 每 22 秒推进一波，敌人血量/数量/种类随波次增强。
- **Boss 一：裂核**（第 4 / 12 / 20… 波，金色）：弹幕型。三段血线三套弹幕（环形齐射 → 旋转弹幕 + 追踪弹 → 更密的双弹幕）。
- **Boss 二：母巢**（第 8 / 16 / 24… 波，绿色）：走位型，不定向你倾泻子弹。它会**在你脚下种腐蚀区**（先亮圈预警 0.95 秒，踩进去持续掉血）、**孵化小怪**、并周期性**蓄力冲锋**（白圈闪烁后直线冲撞）。血线过半后腐蚀区数量和频率都会提升。
- 两种 Boss 都有独立血条（顶部居中）；击破回复 30 生命、+2500 分；Boss 在场时小怪刷新减半。靠近 480px 内会自动集火。
- **精英怪**：第 6 / 10 / 14… 波出现，金色，血条在头顶。
- 生命低于 35% 时屏幕边缘会泛红脉动；受伤/死亡有红闪和慢动作。
- **Esc / P** 暂停，**M** 静音，死亡后 **R / Enter** 重开。
- 最高分写进 localStorage（key: `stardust.best`）。

## 调平衡

数值都集中在两处，改完刷新即可：

- `js/game.js` 顶部的 `TYPES`：每种敌人的 hp / speed / dmg / xp / 颜色。
- `js/game.js` 的 `resetGame()`：玩家初始移速、射速、伤害、冲刺冷却、初始生命。
- 升级卡在 `UPGRADES` 数组里，`max` 是叠加上限，`rare` 控制出现权重。改变打法的卡：**处决**（残血敌人伤害翻倍）、**霜冻**（命中减速）、**环刃**（环绕刀刃 +1，贴身输出流）。
- 连击手感在 `comboMult()` 与 `killEnemy()` 里的 `comboTimer = 1.35`（窗口越长越容易叠高）。
- 刷怪按「每秒几只」控制：`0.75 + 时间×0.013`，上限 4.2/秒，每批数量随时间增加（最多 5 只一批），波次切换时停刷 1.5 秒给喘息。想更硬就改 `updateSpawner()` 里的 `rate`。
- 波次节奏：`update()` 里 `Math.floor(elapsed / 22)` 是每波秒数。

## 打包成 exe

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File tools\build-exe.ps1
```

生成 `dist\Stardust.exe`（约 60 KB，单文件、免安装）。

- **原理**：`csc`（.NET Framework 4.8，Win10/11 自带）编译一个启动器，把 `index.html + style.css + js\` 压成 zip 嵌进 exe 资源；运行时解压到 `%LOCALAPPDATA%\Stardust`，再用系统 Edge 的 `--app` 模式开一个无边框窗口。
- **为什么不用 Electron**：本机 Electron 的 GPU 进程在沙箱里起不来，窗口全黑（试过 `--no-sandbox`、`--in-process-gpu`，只能画出背景层）。Edge 的渲染路径是验证过的，而且体积从 350 MB 降到 60 KB。
- 要求系统里有 Edge（Win10/11 默认自带）；图标由 `tools\launcher\make-icon.py` 生成，源码是 `tools\launcher\Program.cs`。
- **踩过的坑**：DSH 沙箱写出的文件会带 **Low 完整性标签**，效果等同「从网上下载的文件」，Windows 会在普通权限下静默拦下、只有管理员能跑。两个打包脚本末尾都已经用 `icacls /setintegritylevel Medium` 修掉；手动挪动产物时也要确认这个标签。
- 游戏数据（最高分）存在 `%LOCALAPPDATA%\Stardust\profile`。

## 调试

- `?demo`：被动演示（自动绕圈 + 自动选卡），适合截图或插件预览。
- `?demo&t=60`：先静默模拟 60 秒再出画面，并把 `K击杀 L等级 HP E场上敌数 W波次 S分数` 打在屏幕中央——用来快速检查后期密度和平衡。
- `?demo&god&t=90`：无敌模式，用来直接验 Boss 弹幕和阶段切换。
- `?demo&orbs=3`：开局直接给 3 个环刃，用来验贴身流。
- `?demo&maxed`：所有基础卡直接叠满，用来验进化卡是否出现。
- `?demo&cards`：直接弹出三选一界面（含一张进化卡），用来截图。
- 想从某个状态开始调参，改完刷新即可，不需要重新构建。

## 已知限制

- 只针对桌面键鼠，没有做触屏摇杆。
- 音效是 WebAudio 实时合成的，浏览器需要一次点击才能解锁音频（点「开始」即可）。
- 已用 Edge 无头模式逐帧截图验证过渲染与模拟逻辑（菜单 / 12s / 40s / 70s / 死亡），但没有真人长时间试玩，后期平衡可能还需要你反馈。
- 如果页面有报错，左下角会显示具体的 `文件:行号`。
